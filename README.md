# 🚀 Smart Split-Tunneling Wizard (Universal Edition)

Универсальный конфигуратор раздельного туннелирования (Smart Split-Tunneling) для **Windows**, **Android**.

Приложение решает ключевую задачу пользователей VPN: **игры, банки, Госуслуги и российские сервисы работают напрямую с минимальным родным пингом и без блокировок, а заблокированные ресурсы (Discord, YouTube, Instagram, зарубежные сервисы) автоматически идут через быстрый прокси.**

Мастер сфокусирован на **100% проверенных клиентах**, в которых подтверждена безотказная работа VLESS Reality, маршрутизации и раздельного туннелирования.

## 🌟 Возможности программы

### 1. 🖥️ Вкладка «Clash Verge Rev / FClashX (YAML)»
* **Формат:** Mihomo (Clash Meta) YAML.
* **Автоматический деплой в Clash Verge:** применение профиля на ПК в один клик без ручного копирования файлов.
* **Экспорт .yaml для FClashX (FlClash):** готовый профиль с полным списком правил для мобильного клиента на базе Mihomo.
* **Игровой обход:** правила PROCESS-NAME-REGEX для всех обнаруженных игр и лаунчеров направляют трафик в DIRECT.
* **TUN Режим:** преднастроенный стек gvisor, перехват системного DNS (dns-hijack: any:53), автоматическое исключение прямого IP сервера (
oute-exclude-address).

### 2. ⚡ Вкладка «Hiddify (Sing-box JSON)»
* **Формат:** официальная спецификация Sing-box JSON.
* **Мультисерверный селектор:** если в подписке несколько серверов, генерируется переключатель (selector) со всеми узлами.
* **Кроссплатформенный обход:** правила process_name для игр на ПК и правила исключений для сервисов РФ.
* **Экспорт в 1 клик:** сохранение файла smart_singbox.json или копирование профиля в буфер обмена.

### 3. 📱 Вкладка «VLESS Ссылки и QR-код»
* **Динамический QR-код:** мгновенное добавление сервера в мобильный **Hiddify** или **FClashX** прямо с экрана монитора.
* **Копирование активной ссылки:** быстрая передача ссылки VLESS Reality с корректным отпечатком irefox / safari.
* **Пакетное копирование:** экспорт всех серверов подписки для функции «Импорт из буфера обмена».

### 4. 🎮 Вкладка «Игры в DIRECT»
* **Автоматическое сканирование установленных игр:**
  * Интеграция со **Steam** (парсинг библиотек и манифестов ppmanifest_*.acf).
  * Сканирование каталогов **Battle.net, Epic Games, Riot Games, Wargaming/Lesta** и реестра Windows.
  * Ручное добавление любого .exe файла в один клик.
  * Пинг в соревновательных играх (CS2, Dota 2, Valorant, Apex, Overwatch) остаётся чистым и минимальным (напрямую к игровым серверам).

### 5. 🇷🇺 Вкладка «Российские Сервисы»
* Каталог доменов и сервисов для прямого доступа без задержек:
  * **Банки:** Сбер, Т-Банк, ВТБ, Альфа-Банк, Райффайзен, МИР Pay.
  * **Государственные сервисы:** Госуслуги, Мос.ру, Налог.ру, ЕМИАС.
  * **Маркетплейсы и доставка:** Ozon, Wildberries, DNS, Яндекс Маркет, Авито, Самокат, Купер.
  * **Медиа и сервисы:** VK, Кинопоиск, Rutube, Яндекс, Mail.ru.
  * **Зоны Рунета:** .ru, .su, .xn--p1ai.
  * **GeoIP / GeoSite:** автоматический обход диапазона IP Российской Федерации (GEOIP,RU,DIRECT).

## 🛠️ Сборка и установка

### Запуск готового приложения на Windows:
Готовый исполняемый файл:
`
SmartVPNWizard.exe
`
(Приложение не требует установки, готово к запуску из любой папки).

### Сборка из исходников:
`powershell
git clone https://github.com/Andrey15211/Auto-configVPN.git
cd Auto-configVPN
pip install PySide6 PyYAML Pillow qrcode pyinstaller
pyinstaller --noconfirm SmartVPNWizard.spec
`
Исполняемый файл появится в папке dist/SmartVPNWizard.exe.
